# Yugaashvi Motors Website

A responsive motorcycle spare-parts catalogue website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, use VS Code + the Live Server extension.

No build tools or paid dependencies are required.

## Included features
- Yugaashvi Motors brand styling based on the supplied reference image
- Responsive desktop / tablet / mobile layout
- Bike brand and model selector (Honda, Yamaha, Bajaj, TVS, Suzuki, Hero, KTM)
- Model-aware sample spare-parts catalogue and category filters
- WhatsApp inquiry links with pre-filled bike and product details
- Phone, Facebook search and Matara contact information
- Original supplied contact artwork included in `assets/`

## Important before publishing
This is a front-end starter website, not a live inventory or payment system.
- Product names and bike compatibility are demonstration catalogue entries. Confirm every part number, exact model/year compatibility, stock and price with the shop before publishing as verified inventory.
- Prices intentionally show **PRICE ON REQUEST**; no prices or stock levels were invented.
- The WhatsApp number is set to `+94 70 261 3475` based on the supplied contact image. Test it on a phone before launch.
- Facebook currently links to a Facebook search for “Yugaashvi Motors”. Replace it with the shop's exact Facebook page URL when available.
- Add the exact shop address and Google Maps URL when supplied.
- This package does not yet include an admin dashboard, database, customer accounts, online card payments, order tracking or stock management. Those require a backend and secure deployment.

## Customization
- Edit `script.js` to add real bike models, parts, categories and compatibility.
- Edit `styles.css` to change colours and layout.
- Edit `index.html` to update business details, social links and page copy.
